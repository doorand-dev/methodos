# 채팅 간 메시지 감사

채팅끼리 주고받은 지시·결과 전달을 감사할 때 읽는다. 메시지 형식의 정본은 `~/.codex/rules/thread-orchestration.md`의 채팅 간 메시지 절이다.

- 실제 대화에서 보낸 메시지와 받은 쪽의 다음 turn을 표본으로 함께 읽는다.
- 인용한 사용자 원문이 실제로 그 채팅의 사용자 메시지에 있는지 대조한다. 에이전트 요약이 사용자 결정처럼 인용됐는지, 사용자 정정이 반영되지 않은 채 옛 지시가 전달됐는지 본다.
- 추정이 사실처럼 쓰였는지, 받는 쪽이 직접 조회할 수 있는 해시·로그·진단을 반복하는지 본다.
- 같은 지시가 여러 채팅이나 여러 번 전송됐는지, 실행 중인 turn에 보내 묻혔는지, 인계 직전·직후에 보내 처리되지 않았는지 본다.
- 받는 쪽이 에이전트의 의견을 사용자 지시로 처리했거나 권한·범위를 넓힌 흔적을 본다.

- 결과를 당겨 읽을 시점이 있는지, 턴을 끝낸 총괄을 재개할 승인된 완료 통지가 필요한지, 독립 작업이라 보고가 불필요한지 구분했는지 본다. 채팅이 직접 보낼 수 있는 완료 통지를 위해 외부 watcher·예약을 추가했거나, 정본으로 충분한데 전체 대화를 다시 읽게 했는지 확인한다.
