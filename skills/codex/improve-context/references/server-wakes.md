# 서버 알림(채팅 깨우기) 감사

서버·watcher가 담당 채팅에 보내는 알림 메시지와 전달 경로를 감사할 때 읽는다. 전달 방식의 정본은 `~/.codex/rules/codex-wake.md`와 프로젝트의 수신함 절이다.

- 메시지를 조립하는 템플릿 코드와, 실제로 받은 채팅의 해당 사용자 메시지 자리를 함께 본다.
- 받는 AI가 이것을 사용자 지시가 아닌 자동 알림으로 구분할 수 있는 머리말이 있는지 본다.
- 받는 쪽의 다음 행동 진입점(읽을 절·조회 도구)과 사건 식별자 하나만 담는지, 조회로 얻을 수 있는 진단·로그를 반복하는지 본다.
- 같은 사건이 여러 번 전달되는지, retired 채팅으로 가는지, 수락 실패·미수락 전달이 현재 담당에게 다시 가는 경로가 있는지 전달 기록으로 확인한다.
- 받은 채팅의 실제 처리 결과(수락·재개·결과 기록)를 표본으로 본다. 알림이 매번 "기록만 하고 종료"로 끝나면 알림 자체가 필요한지, 담당이 할 행동이 빠졌는지 판단한다.
