# 정기 예약 프롬프트 감사

automation 예약의 프롬프트·대상·주기를 감사할 때 읽는다. 작성 기준의 정본은 `~/.codex/rules/thread-orchestration.md`의 정기 예약 프롬프트 절이며, 여기서는 감사할 때 확인할 것만 둔다.

- 실제 저장된 예약(`$CODEX_HOME/automations/*/automation.toml`)의 prompt·status·rrule·대상을 읽는다. 대화나 인계에 적힌 설명으로 대신하지 않는다.
- rrule이 의도한 실제 시각을 만드는지 펼쳐 확인한다. 같은 목적의 예약이 둘 이상인지, PAUSED 예약이 다른 정본에서 활성으로 취급되는지 본다.
- 대상 채팅이 현재 담당인지, 인계로 retired된 채팅을 가리키는지 프로젝트 routing과 대조한다.
- 프롬프트에 경위·전달 이력·완료 기록·커밋 ID·다른 정본의 값이 쌓였는지 본다. 매회 처음부터 읽히므로 현재 지시만 남아야 한다.
- 프롬프트의 지시가 현재 정본·사용자 결정과 모순되지 않는지 본다. 예약이 서버의 일정 판단에 쓰이면 서버 reader가 그 형식을 지원하는지도 확인한다.
- 최근 실행 결과에서 예약이 매번 무엇을 하고 끝나는지 본다. 매회 같은 조회만 반복하거나 같은 보고를 되풀이하면 프롬프트나 실행 조건을 고친다.
