# handoff 감사

handoff JSON과 그로 시작한 새 세션을 감사할 때 읽는다. 작성 기준의 정본은 `~/.agents/skills/handoff/SKILL.md`이며, 독자 관점의 시작 입력 검토는 [context-novelist](../../context-novelist/SKILL.md)를 따른다.

- 가장 강한 근거는 새 세션의 실제 첫 행동이다. 인계 뒤 새 세션이 무엇을 먼저 했고 사용자가 무엇을 바로잡았는지 대화에서 확인한다.
- 인계 직전 대화의 최근 사용자 결정·정정이 JSON에 빠졌는지 본다. 빠진 결정 때문에 새 세션이 이미 폐기된 순서를 다시 잡았다면 결함이다.
- 작성 시점의 일시적 상태를 계속 유효한 제약처럼 적어, 정상 복구나 재개를 막는지 본다. 예를 들어 "의도된 중지라면 재개하지 않는다"가 실제로는 단순 종료인 상황을 막는 경우다.
- `user_quote`가 실제 사용자 문장인지, 추정이 사실 필드에 섞였는지 본다.
- 끝난 handoff가 남아 다음 세션이 읽을 수 있는 위치에 있는지 본다. 정리 후보 탐지는 `gc`와 겹치므로 여기서는 잘못 읽힐 위험만 판단한다.
