# 트렌드 조사

판단 요약: 사용자의 결정에 맞는 조사 방법을 선택하고, 발견 신호와 검증 근거를 구분한다. 최신성·인기·효과를 확인한 범위만 주장하며, 사례에서 가져올 구조와 적용 한계를 설명한다.

## 조사 범위와 방법

- 먼저 사용자가 무엇을 결정하려는지와 지정한 주제·플랫폼·기간을 파악한다. 정보가 부족해도 합리적인 조사 범위로 진행할 수 있으면 가정을 밝힌다.
- 사용자가 Threads 등 특정 네트워크를 지정하면 우선한다. 지정하지 않았다면 소셜 탐색, 공식 문서, 실제 화면 확인, 사용자 과제와의 비교 중 결정에 필요한 방법을 선택한다. 모든 조사에 특정 네트워크를 강요하지 않는다.
- ‘최신’은 조사 기준일과 명시적인 시간창으로 바꾼다. 사용자가 기간을 정하지 않았다면 주제의 변화 속도에 맞춰 정하고 보고한다. 해당 기간의 근거가 부족해 범위를 넓혔다면 따로 밝힌다.
- 브라우저 조사는 `~/.agents/skills/aside-browser/SKILL.md`를 먼저 읽고 그 진입점을 사용한다. 이 스킬에서 별도 브라우저 연결법을 복제하지 않는다.

## 소셜에서 사례를 발견하고 검증하기

검색 결과의 순서나 추천 피드는 전체 게시물의 인기 순위 또는 최신순을 보장하지 않는다. 검색으로 찾은 사례를 곧바로 ‘가장 인기 있는’, ‘조회수 상위’, ‘최신 추천 순위’로 표현하지 않는다.

인기나 최신성이 판단 근거인 사례는 가능한 한 원문에서 다음을 확인한다.

- 게시물 직접 링크와 실제 게시 날짜. 검색엔진 수집일·수정일을 게시일로 대체하지 않는다.
- 화면에 표시된 조회수와 반응수의 종류·값, 측정 시점과 시간대. 반올림·축약 표시도 그대로 기록한다.
- 확인되지 않거나 노출되지 않는 지표. 비공개·미노출·접근 실패는 미확인으로 두며 0으로 바꾸지 않는다.
- 저자의 제품·서비스와의 관계, 그리고 홍보 주장인지, 시연인지, 실제 사용 결과에 대한 근거인지. 한 게시물에 이들이 섞여 있으면 주장별로 구분한다.

조회수와 좋아요·댓글 같은 반응수는 서로 대체하지 않는다. 게시 후 경과 시간과 측정 조건이 다른 수치를 직접적인 우열 근거로 쓰지 않는다. 저자가 제시한 성과 수치는 저자의 주장으로 표시하고 독립적으로 검증된 결과와 구분한다. 시연 화면만으로 실제 운영 효과를 확정하지 않는다.

인기순을 검증하려면 비교한 모집단·기간·지표·정렬 근거를 설명할 수 있어야 한다. 확보한 표본 안에서만 비교했다면 그 범위를 명시한다. 인기순 검증이 불가능하면 ‘인기순 검증 불가’와 확인한 범위를 밝히고, 발견 사례로 제시한다.

## 구조와 적용 가능성 판단

소셜은 유망한 사례를 발견하는 신호로 쓴다. 제품 구조나 유용성에 대한 판단은 공식 문서, 실제 화면, 사용자가 해결하려는 과제로 교차 검증한다. 접근할 수 없는 근거가 있으면 그 공백을 남기고 결론의 강도를 낮춘다.

벤치마크마다 다음 관계를 설명한다. 정해진 개수의 사례를 채우기보다 결정에 필요한 근거를 확보한다.

- 사례가 해결하는 사용자 과제와 이를 가능하게 하는 구조·흐름.
- 우리 문제에서 가져올 구조와 필요한 전제·변경.
- 적용 한계와 아직 검증하지 못한 효과. 겉모양이나 인기도만으로 도입을 권하지 않는다.

공식 문서는 제공 기능·지원 조건의 근거이며 효과의 독립 실증을 대신하지 않는다. 실제 화면에서 관측한 동작과 그 동작에서 추론한 설계 의도를 나눠 설명한다. 과제 적합성이 확인되지 않으면 적용 가설로 남긴다.

## 접근 실패와 결과 전달

Aside의 UI capture가 실패하면 실제 오류와 확인하지 못한 범위를 기록한다. 다른 브라우저로 우회하지 않는다. 동일 브라우저에서 스킬과 도구가 지원하는 대안으로 확인할 수 있다면 사용하고, 원래 오류·대안·대안으로 확인한 범위를 밝힌다. 대안으로 읽은 텍스트를 화면 확인이나 영상 시청으로 표현하지 않는다.

결과는 판단 요약으로 시작하고, 조사 시간창·측정 시점, 핵심 사례의 직접 출처 링크, 관측 사실과 추론, 적용할 구조와 한계, 미확인 항목을 결정에 필요한 만큼 제시한다. 원문을 열지 못하고 검색 요약만 확인했다면 그 사실을 표시한다. 별도 보고서나 파일은 요청된 경우에만 만든다.
